
# 📖 Manuel Utilisateur - EduPaie

Bienvenue sur EduPaie. Ce guide vous explique comment utiliser l'application au quotidien.

## 1. Démarrer l'application
Double-cliquez simplement sur le fichier **`EduPaie.exe`**. L'application s'ouvre automatiquement.

## 2. Ajouter un nouvel élève
1. Sur l'écran principal, cliquez sur le bouton **Ajouter un élève**.
2. Remplissez le nom, le prénom, la classe, l'année scolaire et le montant total des frais.
3. Cliquez sur **OK**. L'élève apparaît maintenant dans la liste.

## 3. Enregistrer un paiement
1. Dans la liste, **cliquez sur la ligne de l'élève** pour le sélectionner.
2. Cliquez sur le bouton **Fiche élève**.
3. Dans la nouvelle fenêtre, cliquez sur **Enregistrer un paiement**.
4. Saisissez le montant reçu, vérifiez la date, choisissez le mode de paiement (Espèces, Chèque, etc.).
5. Cliquez sur **OK**. 
*(Note : L'application vous empêchera de saisir un montant plus élevé que ce que l'élève doit).*

## 4. Imprimer un reçu
Une fois le paiement validé, il apparaît dans l'historique de la fiche élève.
1. **Cliquez sur la ligne du paiement** dans l'historique (elle doit devenir bleue).
2. Cliquez sur le bouton **Exporter le reçu (PDF)**.
3. Choisissez où enregistrer le fichier sur votre ordinateur et cliquez sur **Enregistrer**.
4. Vous pouvez maintenant imprimer ce fichier PDF ou l'envoyer aux parents.

## 5. Consulter les statistiques
Sur l'écran principal, cliquez sur **Tableau de bord** pour voir :
- Le nombre total d'élèves.
- Le montant total déjà encaissé.
- Le montant total qu'il reste à percevoir.
- La liste des élèves qui n'ont pas encore tout payé
